## 🚀 Իրականացված քայլերը

### 1. String Patching (Տվյալների փոփոխում)
Առաջին փուլում փոփոխվել է ծրագրի կողմից արտածվող տեքստը հենց բինար ֆայլի մեջ:
- **Ֆայլ:** `hello.cpp`
- **Գործողություն:** 
    1. Գտանք "Hello, World!" տողի հասցեն (byte offset) բինար ֆայլում՝ օգտագործելով `grep -oba`:
    2. `hexedit` գործիքով մուտք գործեցինք `.rodata` (Read-Only Data) հատված:
    3. Փոխարինեցինք "Hello" բառը "Hacked" բառով:
- **Արդյունք:** Ծրագիրը սկսեց տպել `Hacked, World!`՝ չնայած սկզբնական կոդը մնացել էր անփոփոխ:

### 2. Logic Patching (Տրամաբանության փոփոխում)
Երկրորդ փուլում շրջվել է ծրագրի տրամաբանական պայմանը (Logic inversion):
- **Ֆայլ:** `logic.cpp` (Գաղտնաբառի ստուգման իմիտացիա)
- **Գործողություն:**
    1. `objdump -d` հրամանով վերլուծեցինք ծրագրի ասեմբլերային կոդը և գտանք `main` ֆունկցիայի համեմատության հատվածը:
    2. Հայտնաբերեցինք `jne` (Jump if Not Equal) հրահանգը, որի օպերացիոն կոդը (opcode) `75` էր:
    3. `hexedit`-ով փոխեցինք `75`-ը `74`-ի, ինչը համապատասխանում է `je` (Jump if Equal) հրահանգին:
- **Արդյունք:** Ծրագրի տրամաբանությունը շրջվեց. սխալ մուտքագրված թիվը դիտվում է որպես ճիշտ, իսկ ճիշտ թիվը (5)՝ որպես սխալ: Սա լիցենզիաների շրջանցման (cracking) հիմնական մեթոդն է:
